
# Focus Frame Photography

## About the project

Focus Frame Photography is a photography project by Archita. It showcases portraits, celebrations, nature, and everyday moments through photographs. The project is built with HTML and CSS.

## Project sections

- **Header:** Displays the Focus Frame name and navigation links.
- **Home / Hero:** Introduces photographer Archita and her photography.
- **Portfolio:** Shows example photographs with captions.
- **About:** Introduces Archita and her photography style.
- **Contact:** Provides a closing message and social links.
- **Footer:** Shows the photographer’s name and copyright text.

The navigation links move visitors to sections on the same page.

## Responsive design

The layout adjusts for smaller screens using CSS media queries. On phones, the navigation menu collapses behind a menu button and the photo gallery changes to a single-column layout.

## Files

- `index.html` — contains the page structure and content.
- `style.css` — contains the colors, fonts, layout, and responsive styles.
- `README.md` — explains the project and how to view it.

## Tools and concepts used

- HTML5
- CSS3
- Flexbox and CSS Grid
- Media queries
- Anchor links for moving between page sections

## How to view the page

1. Keep index.html and style.css in the same folder.
2. Open index.html in a web browser.
3. Resize the browser window to see how the layout changes on a smaller screen.

An internet connection is needed to load the sample photographs and web fonts.
